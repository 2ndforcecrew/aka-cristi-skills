## 叙事技法（→ Writer）

### 变形即身份揭示——变形不是特效，是角色登场

- **表现**：每一次变形都是一次「身份揭晓」。大黄蜂第一次在 Sam 面前变形：先是一辆旧 Camaro 在巷子里自己开门、自己亮灯（观众已经知道这车不对劲），然后车身裂开、零件翻转、站起来——变形过程本身就是角色介绍，不需要任何对白。威震天在胡佛水坝冰封苏醒那场：变形 = 反派正式登场，全片等了 60 分钟才让观众看到完整变形。
- **手法**：变形 = 角色的「出场仪式」。(a) 变形前先给「伪装态」足够的镜头时间（让观众熟悉这辆车 / 这台收音机 / 这架直升机）；(b) 变形过程本身不剪断，一镜到底拍完（变形 = 一个连续动作，不是蒙太奇）；(c) 变形完成后给一个 2-3 秒的「定格」——机器人站稳、镜头推到面部、第一次开口说话。变形前「它是什么」和变形后「它是谁」之间的反差越大，揭示越有力。
- **可迁移**：产品广告的「变形揭示」——产品先以一种形态出现（日常用品 / 普通外观），然后变形为真正的形态（展开、翻转、重组），变形过程就是产品卖点的演示。不需要旁白解释——变形本身就是解释。
- **适用场景**：sci-fi, product-demo, studio-ad

### 平凡主角卷入——普通人是观众的替身

- **表现**：Sam Witwicky 是个为买第一辆车发愁的高中生，不是士兵、不是科学家、不是特工。观众通过 Sam 的眼睛第一次看到变形金刚：他先是害怕（躲在车库）、然后是好奇（跟踪大黄蜂）、最后是参与（把火种源塞进威震天胸口）。全片的「惊奇感」全部由 Sam 的反应来传达——机器人再大，观众的情绪锚点始终是这个普通少年。
- **手法**：主角的「无知」是叙事工具。(a) 主角不知道变形金刚存在 = 观众也不知道，信息同步释放；(b) 主角每次看到变形都做出真实反应（尖叫、逃跑、发抖），观众不需要自己「觉得震撼」，看主角的反应就够了；(c) 主角最后的行动（塞火种源）是全片唯一的人类能做的事——机器人打不赢的仗，要靠人类完成最后一击。
- **可迁移**：产品广告的「普通人主角」——不要让产品专家演示产品，让一个普通用户第一次接触产品：他的惊讶、笨拙、学会、最后熟练，就是观众的学习曲线。产品越复杂，主角越要普通。
- **适用场景**：sci-fi, product-demo, studio-ad

## 镜头语言（→ DP）

### 变形过程的镜头设计（特写零件 + 环绕）

- **表现**：变形不是一个全景镜头拍完，而是一组「零件特写 + 环绕运动」的组合。典型变形镜头约 4-6 秒：(1) 0-1s：车门弹开 / 车顶掀起（特写一个零件的启动）；(2) 1-3s：镜头环绕车身 180°，同时数十个零件依次翻转、滑动、锁定——每个零件的运动都有清晰的起点和终点；(3) 3-4s：机器人站起，镜头从低角度仰拍推到面部；(4) 4-6s：定格 2 秒，机器人第一次看向镜头 / 开口。变形全程镜头不切断——连续运动是「真实感」的来源。
- **技术参数**：环绕速度约 90-120°/秒，镜头与变形体的距离保持 3-5m（太近看不清整体，太远看不清零件）。变形特写用 50-85mm 中长焦（压缩空间感，突出零件层次）；环绕段用 24-35mm 广角（夸大体积感）。关键：每个零件的运动必须「有因果」——A 零件翻开是因为 B 零件顶开了它，不是凭空移动。
- **可迁移**：产品「展开 / 变形」演示——折叠屏手机展开、变形家具、模块化产品组装：先特写一个铰链 / 卡扣启动，然后环绕拍整个变形过程，最后定格在完成态。变形类产品的广告，变形过程本身就是 hero shot。
- **适用场景**：sci-fi, product-demo, logo-animation

### 低角度仰拍（让机器人看起来巨大）

- **表现**：变形金刚站立时约 6-10 米高，全片约 70% 的机器人镜头用低角度（摄影机高度 1-2m，向上倾斜 30-45°）。关键是画面底部永远保留人类参照物——Sam 站在擎天柱脚边只到膝盖，一个士兵跑过只到脚踝。没有参照物，「巨大」就不存在。
- **技术参数**：摄影机高度 = 1-2m（一个站在机器人脚边的人的视角），广角 18-24mm + 向上倾斜 30-45°。画面底部保留参照物（人 / 车 / 路灯），参照物占画面高度约 10-15%。机器人占画面高度 60-80%，头顶留白 10-20%（不要顶格，顶格会失去纵深感）。
- **可迁移**：任何想让产品「看起来大」的场景 = 低角度 + 广角 + 前景参照物。产品 hero shot：把产品放在地面上仰拍，旁边放一个日常物件做比例尺。
- **适用场景**：sci-fi, product-demo, logo-animation

### 机械设计的「零件 1:1 对应」原则

- **表现**：每个变形金刚的机器人形态和载具形态之间，零件是一一对应的——大黄蜂的车门变成胸甲、车顶变成背部、轮胎变成肩膀、引擎盖变成腿部。ILM 的设计规则：变形过程中没有任何零件凭空出现或消失，每一个零件在两种形态中都有明确位置。观众潜意识里会「追踪」零件：车门去哪了？轮胎去哪了？全部找得到，这种「找得到」就是真实感。
- **设计流程**：(1) 选定载具（车型 / 机型）；(2) 拆解载具为 20-40 个主要零件（车门 / 引擎盖 / 轮胎 / 保险杠 / 车顶）；(3) 给每个零件指定机器人形态的位置（车门→胸甲、轮胎→肩甲、引擎盖→小腿）；(4) 设计变形路径：每个零件从 A 点到 B 点的运动轨迹不能穿过其他零件（碰撞检测）；(5) 统一材质：金属漆面 + 外露机械关节 + 发光能量核心。
- **可迁移**：产品设计的「变形逻辑」——可折叠 / 可变形产品的广告：每一个部件在两种形态中都要找得到位置。AI 生图 prompt：`giant transforming robot, car transforming into robot, thousands of mechanical parts mid-transformation, each part has clear origin and destination, silver and gold armor, Michael Bay Transformers aesthetic, cinematic lighting`。
- **适用场景**：sci-fi, product-demo

## 特效语言（→ VFX）

### 数千零件变形（ILM 的变形系统）

- **表现**：一次完整变形涉及 2,000-10,000 个独立零件同时运动。擎天柱的变形约 4 秒，涉及约 10,000 个零件——每个零件有自己的运动轨迹、速度、旋转轴。变形不是「整体缩放 + 换模型」，而是每个零件真实地从 A 位置移动到 B 位置。慢镜头下能看到：车门先弹开 30°、停 0.1 秒、再翻转 90°；轮胎先缩进轮毂、再横向滑动到肩部；引擎盖分裂成三块，分别去到胸部和腿部。
- **实现思路**：在 Houdini/Maya 中用刚体动力学 + 程序化动画。(1) 给每个零件设质量/惯性/运动轨迹；(2) 用「变形曲线」控制整体节奏：启动段（0-20%）慢——第一个零件动起来要让观众「注意到」；加速段（20-70%）快——大部分零件同时运动，视觉最密集；收尾段（70-100%）慢——最后几个零件「咔哒」锁定，给观众一个明确的「完成」信号；(3) 每个零件到达目标位置时加 2-3% 的 overshoot + 回弹（重量感）；(4) 变形全程加金属碰撞火花粒子（每帧 500-2,000 粒）。
- **可迁移**：ComfyUI/Flux prompt：`car transforming into giant robot, thousands of metal parts unfolding mid-air, mechanical transformation sequence, detailed gears and pistons visible, sparks flying, cinematic motion blur, golden hour lighting`。产品变形演示：不要「淡入淡出」切换形态，要让每个部件真实移动——折叠屏展开时，铰链先动、屏幕后展、边框最后锁定。
- **适用场景**：sci-fi, product-demo, logo-animation

### 机械细节密度（近看全是零件）

- **表现**：变形金刚的机器人形态近看没有一块「平」的表面——每一寸都是零件：齿轮、活塞、液压杆、散热片、线缆、铆钉。ILM 的模型单个机器人约 10,000-50,000 个独立部件。特写镜头下，机器人面部就有数百个零件在微动（眼睛的快门、脸颊的散热片开合、下巴的液压杆伸缩）。这种密度让观众相信：这东西是「造出来」的，不是「画出来」的。
- **技术参数**：密度分三层：(1) 结构层——大型装甲板（10-20 块，决定轮廓）；(2) 机械层——关节、活塞、液压杆（100-500 个，决定「这是机器」）；(3) 细节层——铆钉、线缆、散热片、磨损划痕（数千个，决定「这是真的」）。三层缺一不可——只有结构层 = 玩具；只有结构+机械 = CG 感重；三层齐全 = 以假乱真。
- **可迁移**：产品渲染的「细节三层」——产品 hero 图不要只有光滑表面：结构（产品轮廓）+ 机械（接缝、铰链、按钮）+ 细节（材质纹理、磨损、反光）三层都要有。AI 生图时在 prompt 里明确写三层细节。
- **适用场景**：sci-fi, product-demo

## 声音设计（→ Sound Designer）

### 变形音（金属摩擦 + 液压 + 电子）

- **表现**：变形金刚的变形音不是单一音效，而是三层叠加：(1) 金属层——零件摩擦、滑动、碰撞的金属声（高频 2-6kHz，尖锐、短促）；(2) 液压层——活塞推出、液压杆伸缩的「嘶—咔」声（中频 200-800Hz，有明确的 attack 和 release）；(3) 电子层——变形完成时的能量充能「嗡」声（低频 40-80Hz，持续 0.5 秒）。三层同时响，但各有节奏：金属层最密（每 0.05 秒一个撞击）、液压层次之（每 0.2 秒一个动作）、电子层只在开头和结尾出现两次。
- **技术参数**：在 DAW 中分三轨：金属轨（采样真实金属撞击 + 齿轮转动，pitch 随机 ±10% 避免重复感）、液压轨（采样气动工具 + 注射器推拉声，低通滤波到 800Hz 以下）、电子轨（合成器 pad + 正弦波扫频 40→80Hz）。混音比例：金属 50% > 液压 30% > 电子 20%。
- **可迁移**：产品音效设计——任何「开合 / 展开 / 启动」的产品声音都应该是多层叠加：机械声（真实感）+ 气动声（力量感）+ 电子声（科技感）。不要用单一「咔哒」声。
- **适用场景**：sci-fi, product-demo, logo-animation

## 适用提示

- **最佳匹配场景**：需要「变形 / 展开 / 重组」效果的产品广告或科幻项目。需要「机械细节密度 + 重量感」的机器人或工业产品。需要「普通人卷入大事件」的品牌叙事。
- **不适用场景**：温馨家庭广告、极简设计美学（变形金刚的核心是「满」和「密」，不是「简」）、不需要机械感的轻量产品。
- **引用优先级**：核心引用（做变形/机甲项目时——变形过程 + 零件密度 + 变形音三者同时需要）；特定技法借用（仅需变形镜头时，只看镜头语言段；仅需变形音时，只看声音设计段）。
