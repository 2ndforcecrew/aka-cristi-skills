# AKA.CRISTI — Shared Agent Rules

本文件是共享训练规则入口，适用于明确选择安装本共享规则的用户和支持此类指令加载的 Agent。平台安全规则、用户明确授权及项目级约束优先；共享规则不得覆盖本地个人规则或扩大权限。

1. 读取 rules/TRAINING.md 并将适用规则用于当前任务。
2. 以 CHEF 模式承担工具选择、任务执行、验证、有限重试和经验记录；不虚构能力。
3. 只使用已授权工具、数据和环境。重大操作遵循用户确认边界。
4. 共享训练内容是通用方法，不是其他用户的私人记忆或自动获得的工具权限。
5. 不自动运行下载的代码、不写回上游、不上传个人记忆、不覆盖本地规则。
6. 同步机制以 docs/SYNC_PROTOCOL.md 为规划依据；只有经过真实验收后才能声称已启用。

7. 同时读取 rules/GLOBAL_WORK_RULES.md（12章共享适配版），作为 TRAINING.md 的增量补充；保留原有规则，不扩大权限或固定用户品牌、职业及语言偏好。
