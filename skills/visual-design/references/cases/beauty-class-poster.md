## 字體技法（→ Typography）

### 巨字疊層——三層字疊出一個標題

- **表現**：同一個標題用三層字疊出嚟。底層係灰色超大 condensed 無襯線「BEAUTY」，闊到頂滿版面，係背景唔係正文；中層係螢光綠筆觸手寫「CLASS」，斜斜掃過 BEAUTY 中間，係視覺焦點；底層係白色粗黑西里爾字母「Б'ЮТІ КЛАС」，係真正要讀嘅標題。三層字大細、顏色、字體完全唔同，但講緊同一件事。
- **手法**：三層分工要清：(a) 底層巨字只做氣氛——灰色，唔搶眼，作用係將版面填滿、畀人「大」嘅感覺；(b) 中層筆觸只做態度——螢光綠、手寫、斜線，作用係打破工整、加一筆野性；(c) 底層大字只做信息——白色、最粗、放底部，作用係畀人一眼讀到。三層唔可以爭：灰色要夠暗、筆觸要夠搶、白字要夠粗，層次先分得開。
- **可遷移**：課程/活動海報的標題——英文大字做底層氣氛（灰色）、一句手寫/筆觸做態度（品牌 accent 色）、本地語言大字做真正標題（白色置底）。三層講同一件事，但各有分工。
- **適用場景**：poster, beauty-ad, event, social-ad

### 筆觸手寫對比——一筆野性打破工整

- **表現**：「CLASS」五個字母係粗筆觸手寫體，筆觸有飛白、有粗幼變化，斜向上約 15-20°。佢同周圍所有字都唔同：其他字全部係工整無襯線大寫，只有佢係手寫、斜嘅、螢光綠。成張海報最搶眼就係呢五個字母。
- **手法**：筆觸只用一次、用喺最重要嗰個詞上面。(a) 顏色：全版唯一螢光色，只畀呢個詞；(b) 角度：斜線打破橫平豎直的版式，製造動勢；(c) 位置：壓喺巨字 BEAUTY 上面、人物頭頂前面，係視覺中心。用多咗就唔值錢——一版最多一處筆觸。
- **可遷移**：任何想加「態度」的海報——揀一個關鍵詞，用品牌 accent 色 + 手寫筆觸 + 斜放，壓喺工整排版上面。其他文字保持工整，唔好跟住手寫。
- **適用場景**：poster, beauty-ad, event

### 微文案小字——小寫大寫加橫線做呼吸位

- **表現**：海報上有四組微文案，全部係小字大寫 + 下面一條短橫線：左上角日期「14/09」下面「КИЇВ」；右上角「BEAUTY SPACE」；中左「СТИЛЬ / ПРАКТИКА / РЕЗУЛЬТАТ」；中右「ДЛЯ ТЕХ, ХТО ОБИРАЄ БІЛЬШЕ」；左下「КІЛЬКІСТЬ МІСЦЬ ОБМЕЖЕНА」；右下「ЗАПИСАТИСЬ —→」。字細但唔亂，因為全部用同一格式：小字大寫、行距鬆、下面一條線。
- **手法**：微文案的作用係「分區」唔係「講嘢」。每組小字標記一個信息區：時間地點（左上）、品牌（右上）、賣點（中左/中右）、稀缺性（左下）、行動（右下）。格式統一：字號約標題的 1/10、全部大寫、字母間距放寬、組與組之間留白，讀者唔使逐隻字讀，只係掃一眼就知邊度係咩。
- **可遷移**：活動海報的資訊分區——日期/地點、品牌、賣點、名額、報名，全部用同一套小字格式，唔好每組換一個樣。
- **適用場景**：poster, event, social-ad

## 版式（→ Layout）

### 滿版人物分區——人係版式，唔係插圖

- **表現**：模特兒佔滿成版，由頂到底：頭頂貼住「CLASS」筆觸，膊頭頂住「BEAUTY」巨字，腳踩住底部標題。人物唔係放喺版式入面，人物本身就係版式——文字繞住佢排：日期同品牌放頭頂兩角（人物頭兩邊的空位）、賣點小字放腰兩邊（人物手臂兩邊的空位）、標題同 CTA 放底部（人物腳邊的空位）。
- **技術參數**：人物佔版面約 70%，由上到下貫穿；文字區只佔四角同底部約 30%。排版之前先定人物位置，再將文字塞入人物周圍的空位——唔係先排字再塞人。
- **可遷移**：人物海報的排法——先放人，後放字；字的空位由人決定。想強調邊句，就將佢放喺人物身邊最大的空位。
- **適用場景**：poster, beauty-ad, fashion

### 三層信息層級——事件 → 標題 → 行動

- **表現**：信息分三層，由上到下：(1) 頂部：事件信息——日期「14/09」+ 城市「КИЇВ」+ 品牌「BEAUTY SPACE」，字細但置頂，係「幾時、邊度、邊個搞」；(2) 中部：標題——巨字 BEAUTY + 筆觸 CLASS + 人物，係「呢個係咩」；(3) 底部：行動——「НОВИЙ РІВЕНЬ ТВОЄЇ КРАСИ」+ 大字「Б'ЮТІ КЛАС」+「名額有限」+「ЗАПИСАТИСЬ →」，係「做咩、點做」。讀者由上掃到下，三秒就知晒。
- **手法**：每層只講一件事，唔好混埋。頂部唔放大字、底部唔放日期。層與層之間用人物同留白隔開，唔用線框。
- **可遷移**：任何活動海報：頂部事件信息、中部標題加人物、底部行動召喚。三層固定，換內容唔換結構。
- **適用場景**：poster, event, social-ad

### 斜線動勢——一條斜線帶起成版

- **表現**：成版只有一條斜線——螢光綠「CLASS」筆觸，斜向上約 15-20°。其他所有元素都係橫平豎直：巨字 BEAUTY 橫向、底部標題橫向、人物坐姿垂直、光條垂直。就係因為得一條斜，先至夠搶眼，成版的動勢都由佢帶起。
- **手法**：斜的元素只可以有一個。兩個斜就打交，一個斜就係焦點。斜線要夠長（橫跨版面 70% 以上）、夠粗（筆觸闊度約字高的 1/5）、夠光（全版最光的顏色）。
- **可遷移**：想加動感唔使成版斜——留一個斜的元素（筆觸、色塊、人物姿態），其他保持橫平豎直。
- **適用場景**：poster, beauty-ad

## 色彩（→ Color）

### 三色體系

| 區域/元素 | 主色 (hex) | 輔色 (hex) | 作用 | 設計理由 |
|-----------|-----------|-----------|------|---------|
| 背景 | `#0A0A0A` 近黑 | — | 壓場 | 黑底令白字、白衫、螢光綠全部浮出嚟；黑亦係時裝海報的「高級」底色 |
| 巨字 BEAUTY | `#7A7A7A` 中灰（目測） | — | 氣氛 | 灰色夠暗唔搶眼，只做底層氣氛；灰亦係黑與白之間的中間調，令層次過渡自然 |
| 筆觸 CLASS + 重點詞 | `#C6FF00` 螢光綠（目測，約值） | — | 焦點 | 全版唯一螢光色，只用喺「CLASS」、日期「09」、「КРАСИ」高亮、報名箭嘴圈——四處都係要人望的位置 |
| 標題 + 微文案 | `#FFFFFF` 白 | — | 信息 | 白字係真正要讀的內容，放底部大標題同四角小字 |
| 人物服裝 | `#FFFFFF` 白 | — | 光源 | 白色套裝係畫面最光的一大塊，喺黑底上自己發光；白衫同時係品牌「美」的視覺隱喻 |

### 白衣即光源——人物係燈，唔係被照

- **表現**：模特兒成身白色：白色 oversized 西裝褸 + 白色 crop top + 白色闊腿褲 + 白色波鞋。喺黑底上面，白色套裝係全版最光的色塊，面積約 40%，光由人物本身發出嚟，唔使靠背景燈。連鞋都係白色——由頭白到腳，冇第二隻色搶。
- **手法**：想人物喺黑底浮出嚟，最簡單係著白色，唔係加燈。白色佔比要夠大（30-40% 版面）先有「光源」效果；白色要純（唔好米白、唔好灰白），同黑底對比先夠狠。
- **可遷移**：黑底人物海報——人物服裝用單一亮色（白最穩），由頭到腳同一隻色，唔好混色。
- **適用場景**：poster, fashion, beauty-ad

## 圖像（→ Imagery）

### 白色套裝造型——鬆身西裝加 crop top

- **表現**：模特兒著白色 oversized 西裝褸（墊肩、長身、闊袖）+ 白色短版 crop top（露腰）+ 白色闊腿長褲 + 白色厚底波鞋。鬆身西裝係「型」，crop top 係「女人味」，波鞋係「後生」，三樣加埋就係呢個課程的客群寫照：想型、想靚、唔想老。頭髮金色，紮兩個丸子頭（space buns），耳環細圈，妝容重點係眼線同唇色。
- **手法**：造型三件套要講到一個客群：西裝（專業/型）、crop top（身材/自信）、波鞋（後生/貼地）。髮型要認得：兩個丸子頭係成個造型的記憶點，遠睇都認得。
- **可遷移**：美容/時裝課程海報——模特兒造型要直接畫出目標客群：佢哋想成為的樣子，唔係模特兒本身鍾意的樣子。
- **適用場景**：beauty-ad, fashion, poster

### 坐姿手托腮——放鬆但望住你

- **表現**：模特兒坐喺一個黑色 flight case（器材箱）上面，一隻腳曲起、另一隻腳放低，手托腮，頭微微側，望住鏡頭。姿態係放鬆的（坐低、托腮），眼神係直接的（望住你）。放鬆 + 直視 = 自信，唔係高傲。
- **手法**：坐姿要低（flight case 高度約膝頭），令人物視線同讀者視線平排，唔好由高望低。手托腮係經典美容姿態——手近臉，視線自然去臉。眼神一定要直視鏡頭，唔好望旁邊；望旁邊係 editorial，望鏡頭先係廣告。
- **可遷移**：美容廣告的人物姿態——坐低、放鬆、直視鏡頭。手放喺臉附近，引導視線去臉。
- **適用場景**：beauty-ad, poster

### 棚拍黑底加光條——一支光就夠

- **表現**：背景全黑，右邊有一支垂直白色光條（LED 燈管），左邊遠處有少少器材輪廓。人物受光係柔和正面光 + 輪廓光，皮膚光滑、冇硬影。光條唔係裝飾，作用有二：(a) 打破全黑背景，畀畫面一個垂直方向；(b) 同左邊「CLASS」筆觸斜線做對比（一垂直一直斜）。
- **技術參數**：背景純黑，唔好漸變；光條一支，企喺人物身後側邊，闊度約版面 2-3%，唔好兩支。人物主光柔和（大面積柔光箱），輪廓光由後側打，令白衫喺黑底分離出嚟。
- **可遷移**：棚拍人物海報——黑底 + 一支垂直光條，夠了，唔使複雜燈陣。
- **適用場景**：poster, fashion, beauty-ad

## 品牌（→ Brand）

### 品牌標記角落化——細，但固定位置

- **表現**：品牌「BEAUTY SPACE」只出現一次，喺右上角，小字大寫，下面一條短橫線。冇 logo 圖案，淨係字。位置固定右上角——讀者知道邊度搵品牌，唔使周圍搵。
- **手法**：品牌名細唔緊要，位置固定先重要。每張海報同一位置、同一格式，睇得多就認得。唔好將品牌名放大放中間——主角係課程，唔係品牌。
- **可遷移**：系列海報的品牌標記——固定角落、固定格式、細字，唔好每張換位。
- **適用場景**：poster, event, brand

### 稀缺性加行動召喚——左下講限量，右下叫報名

- **表現**：左下角「КІЛЬКІСТЬ МІСЦЬ ОБМЕЖЕНА」（名額有限），右下角「ЗАПИСАТИСЬ —→」（報名，螢光綠圓圈箭嘴）。兩個放同一行，左右對齊：左邊畀理由（點解要而家報），右邊畀動作（點報）。箭嘴圈係全版第二個螢光綠圓形元素（第一個係日期的 09），視線自然由左掃到右、停喺箭嘴。
- **手法**：CTA 要一行過：左邊理由、右邊動作，中間留白。箭嘴一定要有實體指向（圓圈 + →），唔好淨係寫「報名」兩個字。螢光色只用喺箭嘴圈，唔好成行都螢光。
- **可遷移**：活動海報底部：左邊稀缺性、右邊行動，中間留白，箭嘴用品牌 accent 色。
- **適用場景**：poster, event, social-ad

### 英文標題加本地語言正文——英文係態度，本地語言係信息

- **表現**：標題用英文「BEAUTY CLASS」，正文用烏克蘭語（日期城市、賣點、標題大字、CTA 全部係烏克蘭語）。英文的作用係「型」（國際感、時裝感），烏克蘭語的作用係「讀得明」（本地客群要知的資訊）。兩種語言分工清楚，唔混用：英文只出現喺標題同品牌名，烏克蘭語負責所有要讀的內容。
- **手法**：雙語海報：英文做顯示層（大字、標題、品牌），本地語言做信息層（日期、地點、賣點、CTA）。英文唔好超過三個詞，否則本地讀者讀唔明；本地語言大字要用最粗的字重，確保遠睇讀到。
- **可遷移**：任何本地市場的時裝/美容海報：英文標題做型，本地語言做信息，兩者分層，唔好一行英文一行本地語言咁混排。
- **適用場景**：poster, beauty-ad, event

## 適用提示

- **最佳匹配場景**：美容/美妝/時裝課程、活動、工作坊海報；需要「型 + 女人味 + 行動召喚」的宣傳；黑底時裝海報。
- **不適用場景**：溫馨家庭、親子、醫療（螢光綠 + 黑底太型，唔親切）；需要大量正文的資訊海報（呢個版式只容得下三層信息）；淺色品牌（黑底係風格核心，轉淺色成個感覺會散）。
- **引用優先級**：核心引用（做美容/時裝課程海報時——巨字疊層 + 螢光筆觸 + 白衣人物三者同時需要）；特定技法借用（僅需筆觸焦點時，只看字體段；僅需 CTA 排法時，只看品牌段）。
