## 字體技法（→ Typography）

### 無襯線小字加粗標題——標題粗、正文細

- **表現**：全部用無襯線字體，標題粗黑（"Card Title"、"Dashboard"、"Management"、"Neo-Tactile"），正文細小灰字（Lorem ipsum 佔位文案、"Discover what soothes you"）。標題同正文的字重對比大，但字號對比唔大——層次靠粗幼，唔靠大細。按鈕文字用中等字重黑色，唔用粗體。
- **手法**：標題用 600–700 字重、正文用 400 字重、按鈕用 500 字重。字色：標題近黑 `#1A1A1A`、正文灰 `#6B7280`、按鈕黑 `#111111`。唔用襯線字，唔用彩色字——顏色留畀玻璃同 accent。
- **可遷移**：任何玻璃擬態界面——標題粗、正文細、按鈕中等，層次靠字重。
- **適用場景**：ui-kit, dashboard, mobile-app

### 微文案佔位符——短、實、唔花巧

- **表現**：按鈕同輸入框的文字全部係短句："Create workspace"、"Search projects..."、"Start project"、"Find files..."、"Add collaborator"。冇一句多餘，冇標語、冇形容詞。連 toast 都係 "Toast notification"、"We daioly deriapns"（AI 生成圖的亂碼原文，照錄）。
- **手法**：組件文字 = 動作本身，唔好加修飾。按鈕寫動詞（Create / Start / Add），輸入框寫提示（Search... / Find...），狀態寫結果（On / Off / 64%）。
- **可遷移**：UI 文案——寫動作，唔寫形容。
- **適用場景**：ui-kit, dashboard

## 版式（→ Layout）

### 卡片網格——一格一功能

- **表現**：參考圖 01、07、08 全部係卡片網格：每張卡片一個功能（segmented control、卡片、tabs、開關、圖表、團隊、日程）。卡片之間留白均等，唔用線分隔，只用陰影同玻璃區分。儀表板（07、08）將大圖表卡同小數據卡混合排，大卡放中、小卡放邊。
- **手法**：卡片圓角 16–24px，間距 16–24px，唔好細過 12px。卡片唔好貼邊，四周留白等於卡片間距。一屏最多 6–8 張卡，多咗就分頁。
- **可遷移**：儀表板同組件展示頁——一格一功能，卡片網格，唔用線。
- **適用場景**：dashboard, ui-kit

### 浮層分層——玻璃疊玻璃

- **表現**：參考圖 02、04、06 的 modal、toast、搜尋建議全部係浮層：半透明玻璃板疊喺另一塊玻璃上面（modal 疊卡片、toast 疊列表、搜尋框疊背景圖）。層次靠三樣分：下面嗰層更模糊、上面嗰層更實、上面嗰層陰影更重。
- **技術參數**：背景模糊（backdrop-filter: blur）16–24px；浮層不透明度比底層高約 10–15%；浮層陰影比底層陰影深一級。唔好超過三層——三層以上分唔清邊層係邊層。
- **可遷移**：modal / toast / dropdown——浮層玻璃要比底層實、比底層深影。
- **適用場景**：ui-kit, mobile-app

### 淺色霧面玻璃——粉彩只做點綴

- **表現**：參考圖 01–03：底係近白，玻璃面板係半透明磨砂白，tint 係淡淡的薄荷綠、粉紅、淡紫——每張卡片最多一個 tint，而且只佔卡片一角（例如卡片底部一抹薄荷綠）。成版望落去係白色，行近先見到粉彩。
- **手法**：tint 唔好全版鋪，唔好超過卡片面積 30%；tint 飽和度要低（唔好鮮艷），作用係「分區」唔係「上色」。想分兩組卡片，一組薄荷、一組粉紅，就夠了。
- **可遷移**：淺色玻璃界面——底近白、玻璃磨砂白、tint 低飽和、每卡一色、最多佔 30%。
- **適用場景**：ui-kit, dashboard

### 深色觸感玻璃——藍色係唯一的飽和色

- **表現**：參考圖 05（Neo-Tactile）：深灰黑底，玻璃面板係深色半透明，active 按鈕係飽和藍 `#3B82F6`，選中態係青色發光圓環，hover 態會浮起。成版除咗藍同青，冇第三隻彩色。
- **手法**：深色版的規則比淺色版更嚴：(a) 底色要夠深（唔好中灰）；(b) 飽和色只准一個主色（藍）+ 一個光色（青）；(c) 發光效果只用喺「正在發生」的狀態（loading、選中、active），靜態元素唔發光。
- **可遷移**：深色玻璃界面——底夠深、主色一個、光只畀動態。
- **適用場景**：ui-kit, dashboard

### 暖色照片底玻璃——玻璃要配合張相

- **表現**：參考圖 04（AirPods）同 06（智能家居）：玻璃面板直接疊喺照片上面——產品相、家居相。玻璃越透，相越清；玻璃越朦，相越係背景。參考圖 04 的卡片夠透，耳機睇得清；參考圖 06 的面板夠朦，燈光變成暖色光暈。
- **手法**：照片底玻璃要調兩個數：(a) 模糊度——想睇清產品就 blur 細啲（8–12px），想做氣氛就 blur 大啲（20–24px）；(b) 不透明度——產品卡 70–80%、氣氛卡 50–60%。暖色相配暖色玻璃，唔好冷暖打交。
- **可遷移**：照片底的玻璃卡——產品要清就少模糊，氣氛要朦就多模糊。
- **適用場景**：mobile-app, dashboard

### 彩虹邊光——玻璃邊緣的一線光

- **表現**：參考圖 03：玻璃按鈕同卡片的邊緣有一線彩虹光（橙、藍、紫漸變），好似光折射過玻璃邊。唔係成個邊都光，只係一側（通常係上邊或者右邊），好似有光由嗰邊照入嚟。
- **手法**：邊光只做一側，用漸變（唔好單色），闊度 1–2px，透明度由實到虛。想再明顯啲，加少少外發光（同一色，模糊 8px）。唔好四邊都加——四邊都光就變咗霓虹燈。
- **可遷移**：想玻璃更有「真玻璃」感覺——單側 1–2px 漸變邊光。
- **適用場景**：ui-kit

## 組件（→ Components）

### 膠囊按鈕加開關——圓角越大越親切

- **表現**：全部按鈕都係膠囊形（pill，圓角 = 高度一半）：主按鈕 "Create workspace"、"Start project"、"Pro plan"；次按鈕 "Secondary"、"Secondary button"；開關（switch / toggle）全部係膠囊軌道 + 圓形滑塊；分段控制（segmented control）係膠囊入面再分兩格；tabs 係膠囊入面分三格。
- **技術參數**：按鈕高度 40–56px，圓角 = 高度 / 2；開關軌道闊高比約 2:1，滑塊直徑 = 軌道高度 - 4px；分段控制每格最少 64px 闊。主按鈕用實色或漸變（橙、藍、紫），次按鈕用透明玻璃 + 細邊框。
- **可遷移**：玻璃界面的按鈕系統——主按鈕實色、次按鈕玻璃、開關膠囊、圓角等於一半高度。
- **適用場景**：ui-kit, dashboard, mobile-app

### 霧面輸入框加搜尋——輸入框都要識透

- **表現**：搜尋框（"Search projects..."、"With suggestions"、"Find files..."）、文字框（"Text field"）、下拉選單（"Select dropdown"、"Select"）全部係霧面玻璃：半透明底、圓角、細邊框、入面有 icon（放大鏡、+、✓、下拉箭嘴）。搜尋建議（suggestions）係浮層玻璃，疊喺輸入框下面。
- **手法**：輸入框唔好用實白底——用半透明玻璃，令底層隱約透出嚟，成個界面先統一。placeholder 用灰字，輸入後變黑字。icon 放左，清除/下拉放右，唔好兩邊都放 icon。
- **可遷移**：玻璃界面的輸入系統——半透明底、icon 左、動作右、建議用浮層。
- **適用場景**：ui-kit, dashboard

## 狀態（→ States）

### 柔和陰影加模糊——玻璃感的三件套

- **表現**：所有玻璃面板都有的三樣：(a) 背景模糊（backdrop blur）——後面嘅嘢朦咗；(b) 柔和陰影——面板下面一層淡淡的灰影，唔係黑色硬影；(c) 內高光——面板頂部一條極幼的白線，好似光照喺玻璃頂緣。冇咗任何一樣，玻璃感即刻散。
- **技術參數**：blur 16–24px；陰影：0 8px 24px rgba(0,0,0,0.08)，唔好用純黑、唔好用大偏移；內高光：inset 0 1px 0 rgba(255,255,255,0.5)。邊框：1px rgba(255,255,255,0.4)，淺色版用白邊、深色版用淺灰邊。
- **可遷移**：任何玻璃面板——blur + 柔影 + 內高光 + 幼邊框，四樣齊先似玻璃。
- **適用場景**：ui-kit, dashboard, mobile-app

### 狀態反饋——郁、光、浮起，三種反饋

- **表現**：參考圖 05 逐項標明：hover state elevates element（hover 會浮起）、loading state shows animation（loading 會有動畫）、active 係藍色實色、toggle 開係綠色/藍色、"33 Hoter states element"（熱區狀態）。參考圖 02 的 toggle、參考圖 03 的 checkbox ✓，全部都有開/關兩態。
- **手法**：每個可互動元素最少要有兩個態（預設/hover 或 開/關），主按鈕要有三個態（預設/hover/active）。hover = 浮起 2–4px + 陰影加深；active = 顏色加深一級；loading = 圓環轉動或骨架閃爍。唔好只改顏色——顏色 + 位置/光，兩個維度一齊變，用戶先感覺到。
- **可遷移**：玻璃組件的狀態系統——hover 浮起、active 加深、loading 轉動，唔好淨係換色。
- **適用場景**：ui-kit, dashboard

## 適用提示

- **最佳匹配場景**：SaaS 產品、儀表板、管理後台、手機 App、智能家居、組件庫展示；想要「輕、透、現代、唔壓迫」的界面。
- **不適用場景**：需要強烈品牌識別的界面（玻璃風太中性，品牌感弱）；長文閱讀（玻璃面板 + 模糊底會攰眼）；低對比無障礙要求高的場景（半透明 + 淺灰字容易低於 WCAG AA，要另加對比度檢查）。
- **引用優先級**：核心引用（做玻璃擬態界面時——柔和陰影加模糊 + 膠囊按鈕加開關兩者同時需要）；特定技法借用（僅需深色版時，只看深色觸感玻璃一段；僅需儀表板排法時，只看卡片網格一段）。
