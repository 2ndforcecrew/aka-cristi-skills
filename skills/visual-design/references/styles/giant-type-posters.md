## 字體技法（→ Typography）

### 巨字疊層——標題大到遮住人

- **表現**：每張圖都有一個巨字標題，字高佔版面 30–50%，直接疊喺人物相上面："MOVES"（01）遮住模特半個頭、"MARIA"（02）遮住坐姿女人上半身、"BOILER"（03）遮住紅髮女人額頭、"TECHNO KOBIET"（06）壓喺兩個女人下面、"BEAUTY"（08）由模特頭頂穿到落胸口。字唔係擺喺相隔籬，字就係相的一部分。
- **手法**：標題用最粗的 condensed 黑體（800–900），字高至少佔版面三分之一。人物要擺喺字前面定後面，揀一個：人前字後（人遮字，層次深）或者字前人後（字遮人，衝擊強）。唔好半遮半掩——要遮就遮得明顯，留返足夠字形認得出係咩字。
- **可遷移**：海報標題——一個巨字 + 人物相，字疊喺相上面，遮得明顯。
- **適用場景**：poster, event-poster

### 描邊空心字對比——實心字唔夠，加空心字做層次

- **表現**："BOILER"（03）上面有一行描邊空心 "BOILER"（頂部只露一半），實心白字下面、空心描邊字上面，兩層同一隻字做回聲；"MOVES"（01）上面有細一級的描邊字 "WE GOT THE"；"TECHNO KOBIET"（06）上面有紅色細字 "07.03 KLUB MÓZG"。實心字講主題，空心字/細字講補充。
- **手法**：空心描邊字用同一隻字、同一字體、細一至兩級，放喺實心字上面或隔籬，描邊 1–2px。唔好用第三種字體做回聲。
- **可遷移**：標題層次——實心主標題 + 空心/細字副標題，同一隻字。
- **適用場景**：poster

### 豎排旋轉小字——邊位唔好浪費

- **表現**：四邊全部有豎排或旋轉小字："OPEN TILL 1 AM"（03，左邊豎排）、"DUBAI ROBOTICS"（04，左邊豎排）、"23RD MARCH 2021"（04，右邊豎排）、"T&C APPLY"（03，右邊豎排）、"MEET YOUR NEW VIRTUAL FRIEND."（04，左下豎排）。邊位小字係海報的「技術標記」，令人覺得呢張係正式出品。
- **手法**：邊位小字全部大寫、字號細（約標題的 1/20）、旋轉 90 度貼邊放。每邊最多一組，唔好四邊都塞滿。
- **可遷移**：海報邊位——一組豎排小字貼邊，唔好多。
- **適用場景**：poster

## 版式（→ Layout）

### 滿版人物分區——人物就係版式

- **表現**：人物相佔版面 70–100%，冇留白、冇邊框：模特（01）由下到上佔滿版、坐姿女人（02）由下到上、紅髮女人（03）面部特寫佔半版、兩個女人（06）佔上半版、機械人頭（04）佔下半版、金髮女人（08）佔成版。人物唔係插圖，人物就係版式本身。
- **手法**：人物相要裁到貼邊，唔好留白邊。人物視線要望向標題或望出畫面，唔好望住鏡頭以外的無關方向。標題壓喺人物上面時，人物面部至少留一半可見。
- **可遷移**：海報——人物滿版貼邊，標題壓上面，面部至少留一半。
- **適用場景**：poster

### 三層信息層級——巨字、活動資訊、細字

- **表現**：全部海報都係三層：第一層巨字標題（MOVES / MARIA / BOILER / TECHNO KOBIET / BEAUTY）；第二層活動資訊（日期、地點、陣容、票價——"SATURDAY 01 SEOT 2026 / DOORS OPEN 10:00 PM"、"26.07 8 PM / GET 15% OFF"、"TAX: 20 PLN PANIE • 30 PLN PANOWIE"）；第三層細字（條款、網址、主辦方——"18+ EVENT // NO ID NO ENTRY // STRICT SECURITY"、"FOR RESERVATION: +91 7788993371"、"www.mariaevents.com"）。
- **手法**：三層字號比例約 10 : 3 : 1。第一層最粗最大，第二層粗體中字，第三層細字灰色或同色淡一級。三層之間要留白分開，唔好貼埋。
- **可遷移**：活動海報——巨字標題 : 活動資訊 : 細字 ≈ 10 : 3 : 1。
- **適用場景**：poster, event-poster

### 底部信息帶——日期地點一次過

- **表現**：底部有一條信息帶，一次過講晒實用資訊：MARIA（02）底部 "THE WAREHOUSE // INDUSTRIAL AREA // CITY" + "18+ EVENT // NO ID NO ENTRY // STRICT SECURITY"；BOILER（03）底部 "JULY 26.07.2026 SUNDAY / 08 PM ONWARDS / FOR RESERVATION: +91..."；MOVES（01）底部 "ST. JOSEPH COLLEGE OF COMMUNICATION" + 日期框 "DATE: 13TH AUG-26 AFTER 2:45 PM"。讀者睇底部就知去邊、幾時、點去。
- **手法**：底部信息帶用橫線或色塊同主圖分開，資訊用 "//" 或 "•" 分隔，唔好寫長句子。日期、地點、聯絡方式三樣齊。
- **可遷移**：活動海報底部——一條帶，日期 + 地點 + 聯絡，符號分隔。
- **適用場景**：event-poster

## 色彩（→ Color）

### 四色體系

|-----------|-----------|-----------|------|---------|
| 紫粉時裝 | 紫 `#7B2D8B`（目測） | 粉 `#F5A9D0`（目測） | 底 + 服裝 | MOVES（01）的紫粉——底色紫、衫粉紅、眼鏡粉紅，同一色系深淺變化，唔用第二隻彩色 |
| 黑白音樂 | 黑 `#111111` | 白 `#FFFFFF` | 底 + 字 | MARIA（02）黑白——黑字白底、黑衫白鞋，黑白對比行晒成版，音樂海報最穩的做法 |
| 紅橙漸變 | 紅 `#D90000`（目測）→ 橙 `#FF6B00`（目測） | 白 `#FFFFFF` | 底 | BOILER（03）紅到橙漸變底——熱、夜晚、派對感；白字壓上面，對比最強 |
| 螢光綠 | 綠 `#39FF14`（目測） | 黑 `#0A0A0A` | 底 + 字 | Dubai Robotics（04）同 Visionary（05）的螢光綠——綠底黑字或黑底綠字，酸性、科技感，遠睇一眼認到 |
| 青綠加紅 | 青 `#0E5A5A`（目測） | 紅 `#FF1F1F`（目測） | 底 + 字 | TECHNO KOBIET（06）青底紅字——冷暖對比，紅字喺青底上面跳出嚟 |
| 正紅 | 紅 `#E30613`（目測） | 黑 `#111111`、白 `#FFFFFF` | 底 | BEAUTY 紅海報（08）正紅底、黑字、白衫——紅黑白三色，強烈、唔花 |

### 單一飽和底色——一版一隻底色

- **表現**：9 張圖每張只用一隻飽和底色：紫（01）、白（02）、紅橙漸變（03）、螢光綠（04、05）、青綠（06）、灰綠（07）、紅（08）、黑（09）。底色決定成版氣氛，換底色就換感覺。
- **手法**：底色飽和度要夠高（唔好用淡色做底），文字用底色的對比色（黑底白字、白底黑字、綠底黑字）。底色上面唔好再加第二隻彩色做裝飾。
- **可遷移**：海報——一隻飽和底色 + 對比文字色，唔好多。
- **適用場景**：poster

### 黑白加一個 accent——黑白係底，accent 係焦點

- **表現**：MARIA（02）黑白 + 白鞋黑字；Visionary（05）黑底 + 螢光綠字；Beauty Class（09）黑底 + 螢光綠筆觸。黑白行晒成版，accent 只用喺一個位置（筆觸、標題、日期），唔好周圍用。
- **手法**：黑白佔 90% 版面，accent 佔 10% 以下。accent 揀飽和度最高的顏色（螢光綠、螢光黃、螢光粉）。
- **可遷移**：海報——黑白 90% + accent 10% 以下。
- **適用場景**：poster

## 圖像（→ Imagery）

### 人物特寫加巨字遮擋——面要認得，字要壓住

- **表現**：每張圖的人物都係特寫或半身，面部清晰可認，但巨字壓住一部分：MOVES 遮住模特半個頭、MARIA 遮住女人上半身、BOILER 遮住女人額頭、BEAUTY 遮住女人頭頂。遮，但唔遮晒——面至少留一半，否則認唔到人。
- **手法**：人物面部佔版面 20–40%，巨字壓住唔超過面部一半。人物眼神要望向標題或望出畫面。
- **可遷移**：海報人物——特寫、面留一半、巨字壓住唔超過一半。
- **適用場景**：poster

### 時裝造型——衫就係視覺

- **表現**：粉紅 vinyl 外套（01）、黑 hoodie + Nike Jordan（02）、黑西裝 + 紅唇（03）、白 vinyl 套裝（08）、黑皮褸（06）。衫的質感（vinyl 光面、皮、衛衣）係成版第二視覺，僅次於巨字。
- **手法**：衫要揀質感強烈的（vinyl、皮、金屬、毛），唔好用普通棉衫。衫的顏色要同底色呼應（粉紅衫配紫底、白衫配紅底、黑衫配白底）。
- **可遷移**：時裝海報——衫揀質感強烈的，顏色同底色呼應。
- **適用場景**：poster

### 棚拍加光效——光要硬，唔好軟

- **表現**：全部人物都係棚拍硬光：MOVES 的粉紅光打喺模特面、BOILER 的紅光打喺女人面、TECHNO KOBIET 的紅色 LED 眼罩發光、BEAUTY 的棚拍黑底加光條、Dubai Robotics 的綠光打喺機械人頭。光硬、對比強、陰影深，唔用柔光。
- **手法**：主光用一隻彩色硬光（粉紅/紅/綠），唔好用白柔光。陰影要深，唔好補光補到冇陰影。
- **可遷移**：海報棚拍——一隻彩色硬光、陰影深。
- **適用場景**：poster

## 品牌（→ Brand）

### 活動標識角落化——Logo 細細放角落

- **表現**：SJCC FASHION TEAM（01）左上細 Logo + 右上細字、TOY BOY（03）頂部細圓 Logo、RED NETWORK ENTERTAINMENT（03）右下細 Logo、BEAUTY SPACE（09）右上細字。Logo 全部細、全部放角落，唔搶巨字。
- **手法**：Logo 放四角其中一個，唔好放中央。Logo 大細唔超過版面闊度 10%。
- **可遷移**：海報 Logo——角落、細、唔超過闊度 10%。
- **適用場景**：poster

### 日期加地點加 CTA——三樣齊先係活動海報

- **表現**：每張活動海報都有齊三樣：日期（01 SEOT 2026 / 26.07 / 13TH AUG-26 / 07.03）、地點（THE WAREHOUSE // INDUSTRIAL AREA // CITY / LULU MALL RAJAJINAGAR BENGALURU / KLUB MÓZG）、CTA（GET 15% OFF / FOR RESERVATION / JOIN THE TEAM / DOORS OPEN 10:00 PM）。缺一樣，張海報就唔完整。
- **手法**：日期要大（第二層字號），地點用細字，CTA 用 accent 色或色塊。CTA 唔好寫長句子，一句就夠。
- **可遷移**：活動海報——日期 + 地點 + CTA，三樣齊。
- **適用場景**：event-poster

### 英文標題加本地語言正文——標題英文，正文本地話

- **表現**：TECHNO KOBIET（06）標題英文、票價波蘭文 "TAX: 20 PLN PANIE • 30 PLN PANOWIE"；BEAUTY（08）標題英文 "BEAUTY"、正文烏克蘭文 "НОВИЙ РІВЕНЬ ТВОЄЇ КРАСИ"；Beauty Class（09）標題英文、細字烏克蘭文。標題用英文夠型，正文用本地話夠貼地。
- **手法**：標題一律英文（巨字），正文用活動當地語言。本地語言唔好用嚟做標題，否則外國人睇唔明。
- **可遷移**：活動海報——英文標題 + 本地語言正文。
- **適用場景**：event-poster

## 適用提示

- **最佳匹配場景**：音樂活動、派對、時裝海選、品牌發佈、展覽海報；想要「一眼認到、夠型、夠大聲」的海報。
- **不適用場景**：數據報道、報告、說明書（巨字海報講唔到細節）；需要溫柔、優雅感覺的品牌（巨字太硬）；文字量大的海報（巨字佔位太多，正文冇位擺）。
- **引用優先級**：核心引用（做巨字海報時——巨字疊層 + 單一飽和底色 + 三層信息層級三者同時需要）；特定技法借用（僅需邊位小字時，只看豎排旋轉小字一段；僅需酸性綠時，只看螢光綠一段）。
