# Visual language research — reference batches 1–2 (2026-11-24)

Status: observations and proposed transferable rules; not field-validated. This is an extensible research index, not a complete taxonomy. Third-party reference images are not redistributed.

## Transferable decisions
- Composition: establish focal subject, reading order, scale contrast and intentional negative space before adding decoration. Use grid alignment or deliberate exceptions.
- Spatial hierarchy: plan background, structural type/geometry, subject, foreground and finish as optional layers; use masks, occlusion, scale and contact shadows to establish depth. Keep key copy legible.
- Typography: choose type by message; use size, weight, width, spacing and orientation deliberately. Avoid copying distinctive reference layouts or meaningless microtext.
- Color and grading: assign palette roles; echo subject colors where useful; control contrast, skin tones, material fidelity and selective saturation. Monochrome and vivid palettes are equally valid.
- Effects and texture: choose grain, print texture, directional blur, displacement, chrome, glow or brush marks only when they support the concept. Apply selectively, preserve identity and product structure, inspect at output size. Avoid generic filter stacks.
- Art direction: minimal can be powerful through precision, silhouette and contrast; expressive can be powerful through controlled complexity. Neither simplicity nor effect count is a quality metric.
- Web translation: carry editorial hierarchy into responsive layouts, real interactions and accessible text; never treat a static mockup as functional proof.

## Review protocol
Record brief, observed reference principle, chosen technique, intended effect, trade-off and actual output evidence. Inspect thumbnail and full-size views for focal clarity, layer separation, typography, grading, texture and restraint. Compare a clean version against an effect-led version when useful; choose by brief, not personal taste. Mark subjective review separately from hard checks.
