# Skills 单向同步协议 — V0.1 规划

状态：设计规范，尚未在 Skills 产品中实现，未做真实跨 Agent 验收。

## 信任边界

私人训练来源 → 维护者审核与显式批准 → 独立共享训练仓库 → 只读下载、验证、暂存 → 用户本地 managed 规则 → 适配 Agent 读取。

个人记忆、项目、自定义规则永不自动回写共享仓库或私人中央仓库。共享仓库初始保持 Private。个人账号私有仓库 collaborator 权限不应视为只读；若需仅指定朋友读取，选择经过验证的组织 Read 角色或独立只读分发服务。维护者另行批准公开后可使用公开仓库。不得共享私人凭证；不把 token 写入 URL、manifest、日志或 Git。

## 内容、版本和授权

- 默认同步关闭；安装时一次明确选择启用、来源、授权范围及加载目标；可禁用。
- 上游发布经审核的不可变版本、文件清单、每文件 SHA-256、变更说明、最低兼容版本。初始 manifest 只是候选清单，不证明来源真实性。
- 信任起点为用户批准的固定来源和独立可信签名或经授权固定的提交标识；不能把同源自报哈希当作来源认证。
- V0.1 仅允许明确列出的 Markdown 和 manifest，不允许任意可执行文件。远程规则作为受审阅数据，不得扩大工具权限、索要密钥或引入未批准执行动作。
- 私有来源使用用户自己的只读授权或受控下载通道。权限失败保留已有验证版本，不绕过。

## 消费者工作流

1. 检查 Agent 适配、网络、来源授权、已有安装版本及本地改动。
2. 拉取固定发布版本 manifest，校验信任根、版本、防降级、大小上限和允许路径；拒绝路径穿越、链接、非预期文件。
3. 下载至隔离暂存区，核对哈希和规则安全扫描。不匹配、未知签名、超时或权限错误不得替换已有版本。
4. 显示新旧版本差异，权限或新行为变更先获批准。获批低风险规则更新可依用户设定自动接收。
5. 原子切换 managed 目录版本指针，保留上一版本及证据。禁止修改原有 AGENTS.md 或个人记忆，除非用户明确批准添加独立引用。
6. 适配层显式加载 managed AGENTS.md；Codex/Claude Code/Hermes/OpenClaw 各自路径及加载方式需实际验证。没有适配不标记支持。
7. 记录时间、来源、版本、提交、哈希、差异、检查及状态；提供禁用、回滚、卸载，不删除个人文件。

建议受管目录（各平台按实际支持适配）：
- <user-config>/aka-cristi/shared-training/releases/<version>/
- <user-config>/aka-cristi/shared-training/current.json
- <user-config>/aka-cristi/shared-training/sync-state.json

仅写入受管范围，隔离私人记忆与项目目录。同步检查建议在安装、手动刷新或用户启用计划任务时发生；不假设任何 Agent 已有后台同步权限。

## 接入 AKA.CRISTI Skills 的开发任务

独立分支实现 shared-training-sync 模块（manifest 校验、只读获取、事务更新、回滚、审计、平台适配），及安装器可选入口。遵守既有安全门禁，不绕过 SkillSpector 或真实 Agent 测试。首期只同步规则文本，不自动安装 Skill 代码，不授予外部账号访问原私人仓库。

## 验收矩阵（均待实际实现验证）

- 首次安装、更新、重复运行幂等、离线保留旧版。
- 权限拒绝、网络失败、篡改、路径穿越、未批准版本、降级、回滚。
- 个人文件不变；消费者无法自动写回上游；日志无 token。
- 两个独立用户记忆隔离；仅授权共享内容可读。
- Windows/macOS/Linux 及实际 Agent 加载证据分别验证。
- 真实 Agent 读取共享规则并完成代表性任务，记录版本、命令、环境、证据、结果及阻塞。
